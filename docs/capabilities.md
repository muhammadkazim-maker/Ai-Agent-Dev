# OmniVoice Rebuild — Capabilities & Honest Limitations (`docs/capabilities.md`)

## 1. Active Capabilities in Phase 04 (`ov-rebuild-p03-20261111`)

| Capability Domain | Status in Phase 04 | Implementation Details |
| :--- | :--- | :--- |
| **Responsive Portrait & Landscape Shell (320dp–600dp+)** | **ACTIVE** | Full-width title/subtitle header (`app_title_text`, `app_subtitle_text`) with a separate responsive `FlowRow` (`top_header_status_action_row`) for status badge and action icons so words never wrap character-by-character on 320dp–600dp phones or at `1.25x`/`1.5x` font scales. |
| **Single ConversationCoordinator, First-Turn Readiness Gate & `TurnGenerationId` Isolation** | **ACTIVE** | Awaits `RECEIVER_COLLECTOR_ATTACHED` and `SETUP_ACCEPTED` with a bounded timeout (`connectionTimeoutMs`) before starting `AudioRecord` or displaying `LISTENING` (`IDLE -> CONNECTING -> SETUP_ACCEPTED -> LISTENING -> PROCESSING -> SPEAKING -> READY`), debounces duplicate Start presses during active turns, and logs the 9-step `firstTurnLifecycleTrace`. |
| **Microphone Capture, Zero-Dropped First Buffer & Flush-Before-End-of-Turn** | **ACTIVE** | Transitions to `LISTENING` before `audioCapture.startCapture()` so the very first microphone buffer is never dropped, flushes all queued `LISTENING` frames before `signalEndOfSpokenTurn()`, preserves signed 16-bit PCM RMS (`voiceTurnPeakRmsLinear`, `currentRmsLinear`), and rejects silent capture (`SILENT_AUDIO_CAPTURED`). |
| **Single Realtime Audio End-of-Turn & No-Interrupt Config** | **ACTIVE** | Uses `RealtimeInputConfig` (`ActivityHandling.NO_INTERRUPT` + `ActivityDetectionConfig(silenceDurationMs = 700)`) and 960ms of paced 16kHz PCM trailing silence via `sendAudioRealtime` without mixing `session.send(Content("user", emptyList()), true)`. |
| **Non-Leaking Language Mirroring (`GeminiLiveConnectionAdapter`)** | **ACTIVE** | Configures `LiveConfigConstants.AUTHORITATIVE_SYSTEM_INSTRUCTION` via `liveModel(..., systemInstruction = ...)` only, forbidding self-introductions or instruction paraphrasing while mirroring English, Urdu script, Roman Urdu, and mixed Urdu-English. |
| **Complete Native-Audio Playback (`LiveAudioPlaybackAdapter`)** | **ACTIVE** | Uses a ~200ms `AudioTrack.MODE_STREAM` buffer, verifies PCM MIME/sample rate, loops over partial writes, transitions to `SPEAKING` only after `totalFramesWrittenToHardware > 0`, calls `finishStreamForDrain()` (`track.stop()`) on server completion, and drains all frames (`framesReceivedFromServer` / `totalFramesWrittenToHardware` / `hardwarePlaybackHeadFrames`) before `READY`. |
| **Single Clean Session Recovery on Unexpected Interruption** | **ACTIVE** | If `SERVER_TURN_INTERRUPTED` occurs, finishes writing and draining any already-received audio chunks, reports the redacted chronological `turnEventTrace`, and performs at most 1 clean `LiveSession` recreation (`recreateSessionAfterInterruption`) for the next turn. |
| **Connectivity Monitoring & Offline Gate (`LiveNetworkMonitor`)** | **ACTIVE** | Verifies `NET_CAPABILITY_INTERNET` and `NET_CAPABILITY_VALIDATED` before every handshake and voice turn. Invalidates active sessions to `NETWORK_UNAVAILABLE` on internet loss and recovers with at most 1 controlled reconnect when internet returns. |
| **Firebase App Check Debug & Production Play Integrity** | **ACTIVE** | `configureAppCheck(this, intent)` runs in `MainActivity.onCreate()` before `Firebase.ai` access. Debug builds install `DebugAppCheckProviderFactory.getInstance()`; release builds install `PlayIntegrityAppCheckProviderFactory.getInstance()`. |
| **Action Tools Registration (Phase 05+)** | **ZERO_TOOLS (Phase 04)** | `tools = emptyList()` (`registeredActionToolsCount = 0`). |
| **Accessibility Service / Call Control** | **NOT_CONFIGURED (Phase 04)** | Intentionally deferred in Phase 04 per `PROJECT_CONTRACT.md`. |

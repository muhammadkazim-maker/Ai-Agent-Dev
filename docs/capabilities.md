## 2. Known Limitations & Honest Boundaries
1. **Physical-Device End-to-End Google Search Grounding Pending Execution**: Automated JVM and Robolectric suites verify tool call handling, selective skipping, cache TTL expiration, hostile-page sanitization, budget/cancellation, clickable source UI, and `COPY DIAG` section `[13.]` using deterministic test drivers. Live network round-trips from `gemini-3.1-flash-live-preview` -> `search_public_information` -> `gemini-3.8-flash` (`Tool.googleSearch()`) -> `"Kore"` spoken summary on a physical phone remain to be executed by the operator.
2. **Model-Initiated Tool Call Dependency in Live Audio Sessions**: Because Google Search grounding metadata is not exposed natively inside `LiveServerContent` in `firebase-ai:17.15.0`, the Live model decides when to emit `LiveServerToolCall("search_public_information")`. If the Live model answers a current-info utterance directly from parametric memory without emitting a tool call, `ConversationCoordinator` explicitly marks the turn `UNVERIFIED_BACKGROUND_ONLY` so users are not misled into thinking web sources were verified.
3. **Hostile Directive Detection Scope**: `UntrustedContentSanitizer` combines strict URL allowlisting (`https://` public hosts only), HTML/script/bidi stripping, `DiagnosticRedactor` redaction, and structural instruction separation (`UNTRUSTED_PUBLIC_WEB_DATA_ONLY` envelope), which neutralizes known script/prompt/device-action/exfiltration payloads; novel phrasing outside matched rules remains bounded by having zero action tools (`registeredActionToolsCount = 0`) and strict output schema limits.
4. **Lock-Screen UI Surface Not Yet Built**: `LockScreenSafePublicSummary` provides the non-private public-data projection ready for a future lock-screen phase; lock-screen wake/display UI is intentionally deferred to a later phase.
5. **Physical 20-Minute Endurance & Explicit Half-Duplex Boundaries**: Multi-minute physical-phone audio/thermal endurance and HAL acoustic tail behavior remain hardware-verified only on a physical device, and the microphone stays disabled during `THINKING` and `SPEAKING` (`HALF-DUPLEX EXPLICIT`).
